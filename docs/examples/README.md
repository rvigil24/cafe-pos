# Sanitized backup example

`cafe_pos_example.db` is a schema-version-2 SQLite backup generated only from
fictitious Cafe POS data. It contains one category, product, table, paid order,
order item, cash payment, and the standard settings rows. It contains no data
copied from a real device or customer.

Use it for restore demonstrations and schema inspection. Its expected report
totals are one paid order, one unit, and net sales of 150 cents.
